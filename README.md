# 智能课堂辅助教师（Vue + Python）

一个面向课堂教学场景的智能教学助手项目，支持 AI 对话、多模态识别（语音/图片/视频）、课堂实时互动、课后复习整理与知识归类。

## 项目目标
- 为教师提供课堂前、中、后的完整智能辅助能力。
- 将“输入（课堂内容）→ 理解（AI处理）→ 反馈（互动与总结）”形成闭环。
- 在保证可扩展的前提下，先实现最小可用版本（MVP），再逐步演进。

## 核心能力
- AI 对话助教：课堂问答、教学建议、即时解释。
- AI 语音识别：课堂语音转写、关键词提取。
- AI 图片识别：板书/作业拍照识别、内容归类。
- AI 视频识别：课堂视频分段分析、行为与内容标注。
- 实时课堂互动：提问收集、答题反馈、互动统计。
- 复习整理：自动生成课堂摘要、知识点与错题清单。

## 技术栈（规划）
- 前端：Vue 3 + TypeScript + Vite
- 后端：Python（FastAPI）
- AI 能力层：ASR / VLM / 多模态服务（可替换）
- 数据层：PostgreSQL + Redis + 对象存储（图片/视频）
- 部署：Docker + Nginx + CI/CD

## Monorepo 结构（已启用）

- 工作区管理：`pnpm workspace`
- 目录约定：
  - `apps/web`：前端应用（已实现）
  - `apps/server`：后端服务（预留）

### 常用命令（在仓库根目录执行）

- 安装依赖：`pnpm install`
- 构建前端：`pnpm build` 或 `pnpm build:web`
- 本地开发前端：`pnpm dev` 或 `pnpm dev:web`
